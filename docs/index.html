A simple machine-learning pipeline turns language into a prediction.

STEP 01

Plot summary

Your movie synopsis becomes the input text for the classifier.

▤
STEP 02

TF-IDF

Text is converted into numerical features based on word importance.

◈
STEP 03

Naive Bayes

The trained model estimates the probability of each genre class.

✧

The highest-scoring genre is returned with alternative predictions.
